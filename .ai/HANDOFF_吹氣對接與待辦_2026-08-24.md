## 1. ★ 這次最重要的發現（別讓它再發生）

`NgAirBlowService` 的判定是：**收到的字串含 `NG`（不分大小寫）就吹**。

我方原本沿用 `模號檢驗/相機版` 的 JSON：

```json
{"type":"blow","channel":0,"reason":"MISMATCH","id":"T000123","expect":"M108/14",...}
```

**整串字沒有 `NG` 這兩個字** → 對方當雜訊丟掉。

> **症狀：混料照樣判、兩邊 log 照樣寫、就是不吹，而且雙方都不報錯。**
> 更陰的是 `reason=NG` 那種會**碰巧**觸發（JSON 裡剛好出現 NG）
> → 變成**混料不吹、不良品會吹**，看起來「有時候會動」，更難查。

已修。現在送：

```
NG reason=MISMATCH id=T000123 expect=M108/14 got=M17/14 conf=0.97/0.96 ts=13:47:42.309
```

| | 改前 | 改後 |
|---|---|---|
| Port | 5001 | **5000** |
| 格式 | JSON | **NgText**（`Format` 可切回 `Json` 給相機版那支自製監聽程式） |
| 連線 | 每次重連 | **長連線**（依對方建議，斷線自動重連重試一次） |
| 編碼 | UTF-8 | **ASCII**（非 ASCII 先換 `_`；對方用 `Encoding.ASCII` 解） |

設定畫面有「送 JSON 格式」勾選 + **紅字警告**（勾錯是無聲失敗）。

⚠ **真服務在開發機跑不起來**：`OpenDeviceAndDiscoverDo()` 在 `listener.Start()` **之前**，
沒有研華 EtherCAT 卡就直接拋 → 只能用複刻判定邏輯的 mock 驗（已回饋給對方，見 §3）。

## 4. ★★ 等等要做的東西（依優先序）

### ① 現場對接吹氣 —— **最急，東西剛接好就該去驗**

```
1. 對方那台起 NgAirBlowService → log 要看到 [TCP] Listening on port 5000
2. 驗埠（⚠ 用 Test-NetConnection，不要用 ping，防火牆常擋 ICMP）
     Test-NetConnection <對方IP> -Port 5000    → TcpTestSucceeded 要 True
3. 站端 App → 登入 eng1 → 系統／吹氣觸發設定
     填對方 IP、Port 5000 → 勾「啟用」→ 儲存 → 按「測試吹氣」
     對方 log 應出現 [TCP] Received ... "NG reason=TEST ..." 且吹嘴動作
4. ★ 用碼錶量「工件從拍照位走到吹嘴」的時間 → 填進「延遲（毫秒）」→ 再按一次測試吹氣對時機
5. 最後才跑真實產線驗混料
```

⚠ 對方吹 **0.3 秒**自動關；吹氣期間再收到會**重新計時延長**（不會被打斷）。
⚠ 設定存 `configs/blow.json`，**存檔即生效免重啟**；要複製到別台就搬這個檔。

### ② 真實 GPU 訓練接上去

我測的是**照契約寫的假腳本**（驗的是驅動／進度／閘門／上架這條路，不是訓練本身）。
真腳本接上去只要在**父端** `AIVision.Api/appsettings.json` 的 `Training` 段填：

| 欄位 | 填什麼 |
|---|---|
| `Enabled` | `true` |
| `YoloEntry` | `train_yolo_head.py` 完整路徑 |
| `CrnnEntry` | `train_crnn.py` 完整路徑 |
| **`CrnnRehearsalPath`** | **排練集資料夾（不填 CRNN 會被擋——這是刻意的）** |
| `YoloMohaoWeights` / `YoloXuehaoWeights` | 現有 head 權重（熱啟動基底 / 配對用） |

然後父端監控右上角「自我強化訓練」→ 選資料集 → 開始訓練。
**契約完全沿用相機版，現有 python 腳本一行都不用改。**

### ③ 決策：本機接管準確率 ~61%

8/17 就掛著。中央 CRNN `b3` 是 100%，本機是雙 head ONNX `baseline`（較舊）。
**彙總腳本現在會自動把中央 vs 本機的正確率分開算出來** → 可以拿數據談了。
選項：接受降級運轉（定位就是「不停線」不是「同等準確」）／升級本機模型。

### ④ ROI 疊在預覽上（做法已定，等一聲令下）
