## 2. ★核心定案（不要再反覆）

### ① 吹氣：**只加 TCP，PLC 那條完全不動**
AIVision **本來就有**混料氣吹（`IoCommand.Blow()` 寫 PLC）。相機版另外走 TCP 的原因是
**現場 IO 卡在另一台電腦上**（妍華那台），PLC 那條吹不到它 → 兩條**並存**。

- 接線點：`VerifyMoldCodePairCycleCommandHandler` 寫完 PLC IO 之後**只排隊不等待**。
- 協定與相機版**完全一致** → 現場那支 IO 監聽程式**不必改**。
- 設定存 `configs/blow.json`（**不是 appsettings**）：`DelayMs` 要現場邊試邊調，
  該檔以 `reloadOnChange:true` 掛進設定系統 → **存檔即生效**。

### ② 自我強化訓練：**跑父端**，兩道人為關卡不可省
1. 訓練**永不覆蓋** production 權重 —— 一律開新 run 夾。
2. 過閘門只代表「可以考慮」→ **使用者按上架**才進登錄庫 → **還要**按「設為現用」才生效。
   - 中央端**刻意不讓 python 自己上架**（manifest 送 `register_catalog=false`），
     候選一律回 API 走既有 `/api/models` 流程（md5／溯源／版本不可變）。
   - **CRNN 沒設 rehearsal 排練集就不准訓** —— 這是防「一批修正資料把舊標籤能力洗掉」
     （災難性遺忘）的唯一防線。

### ③ 訓練的輸入＝**自帶正解的混料歸檔**
`_MISMATCH\yyyyMMdd\exp_M108-14_got_M17-14_*.jpg` —— **檔名本身就是標註**，
不需要另一份標註檔（多一份就有不同步風險）。只存混料（NG 沒有正解可寫），預設**開啟**。

### ④ 與 python 的契約完全沿用相機版
`training_request.json`(schema_version=1) → stdout `[PROGRESS] n msg` → `training_result.json`
→ exit `0`=過／`2`=沒過。**現有訓練腳本一行都不用改**。

## 3. 主頁影像預覽：三個 bug 疊在一起（都會造成「全黑且毫無線索」）

| # | 根因 | 修法 |
|---|---|---|
| ① | `appsettings.Development.json` **被無條件載入**，把 `Devices:Camera:Type` 蓋成 `Fake` → DI 永遠解到 `FakeCameraPort` | 改成要 `AIVISION_ENVIRONMENT=Development` 才載入 |
| ② | 相機開得起來卻在套參數時**整個拋出**（onsemi NOIP1SN1300A 的 `GainSelector` 回報可寫但實際不可寫） | selector 單獨 try/catch；**開相機的「一次套用全部參數」改逐項 best-effort** |
| ③ | **過曝**：`appsettings` 的 `Devices:Camera:Options` **根本沒人讀**，真正生效的是 `configs/camera-ids.json`（原 15000µs/Gain 2.0＝類別預設） | 改成 `模號檢驗` 實測值 **1300µs / Gain 1.0**；死設定標上 `//Options` 警告 |

⚠ **副作用**：①同時也讓 PLC 從 Fake 變回 `Modbus`（僅註冊、不自動連線）。
要回舊行為設 `AIVISION_ENVIRONMENT=Development`。

第一個 run 早跑完，守衛沒被觸發）。把假腳本拉長重測才真的擋下。

## 7. 踩坑 / 工作紀律

- **`Kestrel:Endpoints` 會反過來蓋掉命令列**（連 `--urls` 都失效）→ 綁定要用 `"Urls"` 鍵。
  優先序：appsettings < 環境變數 < 命令列。
- **「開發用」的設定檔不能無條件載入** —— `appsettings.Development.json` 把相機/PLC 蓋成 Fake，
  害現場全黑且毫無線索。要嘛用環境變數把關，要嘛就別留。
- **設定有兩個地方時，一定要標明哪個才是真的** —— `Devices:Camera:Options` 沒人讀卻長得很像真的。
- **HTTP header 只吃 latin-1** → 中文路徑一律走 form 欄位（POC 為此卡過一整天）。
- WPF：`Background` 寫在元素上會壓過 Style Trigger；`Application` 要寫完整名稱（撞 `AIVision.Application`）。
- **只打 API 不夠** —— 今天兩個 UI bug 都是在「API 全綠」的情況下存在的。
- **自己的測試也會說謊** —— G9 那次差點寫成假通過，要追到「守衛真的被觸發」才算數。
- 測試若會污染真實資源（模型登錄庫！），**做完一定要刪乾淨並在紀錄裡寫明**。
- 動 `.ai` 要同步 `status.json` + 跑 `python D:\專案管理\process\build_dashboard.py`。
