```
┌─────────────────────────────────────────────────────────────────┐
│                    PRESENTATION 展示層                          │
│                  AIVision.Presentation.Wpf                      │
│  Views (XAML) + ViewModels (MVVM) + Converters                 │
└────────────────────────────┬────────────────────────────────────┘
                             │ 依賴
┌────────────────────────────┴────────────────────────────────────┐
│                    APPLICATION 應用層                           │
│                  AIVision.Application                           │
│  Ports (介面) + Commands (CQRS) + Services (業務邏輯)          │
└────────────────────────────┬────────────────────────────────────┘
                             │ 依賴
         ┌───────────────────┴───────────────────┐
         ▼                                       ▼
┌────────────────────┐              ┌────────────────────────────┐
│   DOMAIN 領域層    │              │  INFRASTRUCTURE 基礎設施層  │
│  AIVision.Domain   │              │  AIVision.Infrastructure   │
│  實體 + 值物件     │              │  相機/PLC/AI/DB 驅動       │
└────────────────────┘              └────────────────────────────┘
```

## 核心技術棧

| 類別 | 技術 |
|------|------|
| 框架 | .NET 8.0 (Windows) |
| UI | WPF + MVVM (CommunityToolkit.Mvvm) |
| 資料庫 | SQLite + Dapper |
| CQRS | MediatR |
| 相機驅動 | IDS Peak SDK、海康威視 SDK |
| 通訊協定 | Modbus TCP (PLC)、RS-232 (光源) |
| AI 推論 | AINAVI HTTP API、EdgeHub Workflow |
| 報表匯出 | ClosedXML (Excel) |
| 韌性策略 | Polly (重試、熔斷) |

## 主要功能模組

- ✅ 工單管理系統
- ✅ 自動運行 (Auto Run) - PLC 觸發檢測
- ✅ Line Scan 相機控制 (IDS Peak / Hikvision)
- ✅ 光源控制 (TCP / RS-232) - 含工作/待機亮度自動切換
- ✅ AI 推論整合 (單張/批量/Workflow)
- ✅ 歷史圖庫管理
- ✅ 生產統計分析
- ✅ 動態瑕疵類型管理
- ✅ AI 模型管理
- ✅ Excel 報表匯出
- ✅ 離線檢測模式
- ✅ **瑕疵過濾判定** - 依尺寸/距離規則智慧過濾 🆕
- ✅ **Overlay 瑕疵標註** - 瑕疵輪廓即時疊加顯示 🆕
- ✅ **圖片檢視器** - 獨立視窗放大瀏覽 🆕
- ✅ **自建 YOLO Server 支援** - 可替換 AINAVI 推論後端 🆕
- ✅ **權限管理系統** - 三級權限（作業員/工程師/廠商） 🆕

## 開發歷程

### 主要里程碑
- **2024-11**: 基礎架構建立、PLC 握手機制、Line Scan 相機整合
- **2024-11**: 動態瑕疵類型支援、模型管理系統
- **2024-11**: 工單管理優化、統計數字問題修復
- **2024-11**: 光源控制 (TCP/Serial)、Workflow 整合
- **2024-12**: 程式架構文件完善、客戶功能說明文件
- **2025-12**: 瑕疵過濾系統、Overlay 渲染優化、模型管理增強 🆕

### 近期更新 (2025-12)
- **權限管理系統**: 三級權限控制（作業員/工程師/廠商），從 appsettings.json 配置
- **瑕疵過濾判定系統**: 依尺寸/距離規則智慧過濾瑕疵
- **Overlay 渲染優化**: 改用 Bgr24 格式,提升效能
- **光源亮度自動控制**: Auto Run 自動切換工作/待機亮度
- **模型配置管理**: 跨層模型配置提供者 (IModelConfigProvider)
- **圖片檢視器**: 獨立視窗放大瀏覽檢測影像
- **相機熱機流程**: Auto Run 啟動時預熱相機
- **YOLO Server 開發指南**: 自建推論服務的完整文件

### 歷史更新 (2024)
- PLC 訊號優化 (取像第一時間回應,減少延遲)
- Line Scan LineRate 覆蓋邏輯修正
- 影像編碼修復 (JPEG 格式)
- Workflow API 整合
- 離線檢測功能新增
