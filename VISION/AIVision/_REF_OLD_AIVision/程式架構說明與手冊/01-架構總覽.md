# AIVision 架構總覽

## 專案簡介

AIVision 是一套基於 **Clean Architecture（乾淨架構）** 開發的 **AOI 自動光學檢測系統**。
系統支援 Line Scan 相機、PLC 自動觸發、AI 推論（含 Workflow 多模型串接），並具備完整的生產統計、瑕疵過濾、歷史查詢功能。

### 核心特色
- **多模型支援**：單一模型推論 / AINAVI EdgeHub Workflow 多模型串接
- **智慧瑕疵過濾**：依尺寸、距離規則過濾瑕疵，減少誤判
- **光源亮度控制**：Auto Run 自動切換工作/待機亮度
- **模型管理系統**：支援多模型配置與快速切換
- **自建推論 Server 相容**：可替換為自建 YOLO Server

## 依賴規則

**核心原則：內層不依賴外層**

```
Presentation ──依賴──▶ Application ──依賴──▶ Domain
                              │
                              ▼
                       Infrastructure
                       (實作 Ports)
```

1. **Domain（核心）**：純業務邏輯，不依賴任何外部套件
2. **Application（應用）**：定義 Ports 介面，編排業務流程
3. **Infrastructure（基礎設施）**：實作 Ports，處理外部依賴（DB、相機、PLC）
4. **Presentation（展示）**：WPF UI，透過 DI 調用 Application 層

## 技術棧

| 類別 | 技術 |
|------|------|
| 框架 | .NET 8.0 (Windows) |
| UI | WPF + MVVM (CommunityToolkit.Mvvm) |
| 資料庫 | SQLite + Dapper |
| CQRS | MediatR |
| 相機驅動 | IDS Peak SDK、海康威視 SDK |
| 通訊協定 | Modbus TCP (PLC)、RS-232/TCP (光源控制) |
| AI 推論 | AINAVI HTTP API、EdgeHub Workflow、自建 YOLO Server (可選) |
| 瑕疵處理 | 瑕疵過濾服務 (尺寸/距離規則)、Contour Overlay 渲染 |
| 報表匯出 | ClosedXML (Excel) |
| 韌性策略 | Polly (重試、熔斷) |
| 日誌系統 | Microsoft.Extensions.Logging |

## 核心設計模式

| 模式 | 應用位置 | 說明 |
|------|---------|------|
| Clean Architecture | 整體結構 | 六邊形架構，依賴反轉 |
| MVVM | Presentation 層 | View/ViewModel 分離 |
| CQRS | Application 層 | Command/Query 分離 |
| Repository | Application/Infrastructure | 資料存取抽象 |
| Port/Adapter | Application/Infrastructure | 介面定義與實作分離 |
| State Machine | Domain/AutoRun | 自動運行狀態管理 |
| Strategy | DefectFiltering | 可替換的瑕疵判定策略 |
| Adapter | ModelConfigProvider | 跨層配置適配 |

## 核心服務介面 (Ports)

### 硬體控制
| 介面 | 說明 |
|------|------|
| `ICameraPort` | 相機控制（取像、參數設定） |
| `ILineScanCameraPort` | Line Scan 相機專用控制 |
| `IPlcPort` | PLC Modbus TCP 通訊 |
| `ILightPort` | 光源亮度控制（含工作/待機模式） |

### AI 推論
| 介面 | 說明 |
|------|------|
| `IAiInferencePort` | AI 推論服務（支援 AINAVI / 自建 YOLO） |
| `IAiModelPort` | 模型載入與管理 |
| `IWorkflowService` | Workflow 多模型串接服務 |

### 業務服務
| 介面 | 說明 |
|------|------|
| `IDefectFilteringService` | 瑕疵尺寸/距離過濾判定 |
| `IContourOverlayRenderer` | 瑕疵輪廓 Overlay 渲染 |
| `IModelConfigProvider` | 模型配置提供者 |
| `IInspectionImageService` | 檢測影像處理與儲存 |
