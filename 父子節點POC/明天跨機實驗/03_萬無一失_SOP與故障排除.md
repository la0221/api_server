## 0.6 現場網路：自帶 USB 網卡拉「私網同網段」（明天用這個，不碰公司網／免掃描）

當現場**不能上公司網／不能用內建網卡連**時，自帶 **USB 網卡**在兩台之間拉一條**私有同網段**——不碰公司網、IP 自己設（**不需要掃描**，兩邊 IP 你都知道），真正的跨機 TCP 測試照常跑、數字最準。

1. **接線**：兩台各插好 USB 網卡（若不是隨插即用，先裝驅動→**驅動檔也放隨身碟帶去**）。用一條網路線把兩張 USB 網卡**直連**（現代網卡自動 MDIX，普通線就行），或各接一顆小 switch。
2. **設靜態 IP（只設在 USB 網卡那個介面，別動內建網卡）**：控制台\網路連線 → 對 **USB 網卡**右鍵內容 → IPv4 → 手動：
   - 父機 USB 網卡：IP `192.168.50.1`、遮罩 `255.255.255.0`、**閘道留空**、DNS 留空。
   - 子機 USB 網卡：IP `192.168.50.2`、遮罩 `255.255.255.0`、閘道留空。
   - （只要**同網段、不同號**即可；挑一個和現場現有網段不衝突的，如 192.168.50.x。）
   - Windows 若問「公用/私人」→ 選哪個都行（防火牆規則設成全 profile），選「私人」最省事。
3. **父機**：右鍵管理員跑 `dist\父_開防火牆8770`（放行 8770，已含 ICMP）；父端 `真實測試\1_父_真GPU推論_存收圖` 監聽 `0.0.0.0`＝所有介面（含 USB 網卡），不用特別綁。
4. **子機驗證**：PowerShell `Test-NetConnection 192.168.50.1 -Port 8770` → `TcpTestSucceeded : True` 才開跑（**別用 ping**）。
5. **子機開跑**：`真實測試\2_子_RouteA真前處理送出_跨機` → 輸 **`192.168.50.1`**（父機 **USB 網卡** IP）。

⚠ **一定要挑對 IP**：父機現在有**兩個以上 IPv4**（內建網卡 + USB 網卡），子機**只能連 USB 網卡那個 `192.168.50.1`**，別填到內建網卡的 IP。子機自己也用 USB 網卡的 `192.168.50.2`＝同網段直連、免閘道。

> 檔案怎麼上機（離線）：把 **`dist` 整夾壓縮 → 隨身碟 → 兩台解壓**。子機做真前處理：`環境配置\子\` 已**完全離線自足**——**內含 `python-3.13.7-amd64.exe`（本機同版）＋ `wheels\`**。子機沒 Python 就先跑那支安裝檔（勾 Add to PATH），再跑 `安裝_子_離線.bat`（`--no-index` 免網）。父機真 GPU 那套是線上裝的 → **真 GPU 父機須是「已有 lens-gpu 環境」那台**（新離線機裝不起 torch）。

## 1. 父機（接收端）操作 — 3 步

> **父機是 Linux 的話**：改看 `dist/linux/README_LINUX.md`（`chmod +x run_parent_stub.sh && ./run_parent_stub.sh`；防火牆用 `ufw`/`firewalld`；IP 用 `hostname -I`）。下面是 Windows 父機流程。

1. **（首次一定要做）開防火牆**：對 `父_開防火牆8770_右鍵系統管理員.bat` **按右鍵 → 以系統管理員身分執行**。
   - 看到 `Done. ... allow inbound TCP 8770` 就成功；若說要管理員 → 就是你沒用右鍵管理員。
2. **記自己 IP**：開 cmd 打 `ipconfig`，找 **IPv4 位址**（例 `192.168.0.222`）。抄下來。
   - ⚠ 父機常有**多個 IPv4**（有線、WiFi、VirtualBox `192.168.56.x`、WSL/Hyper-V `172.x`…）。**挑「與子機同一網段」那個**（先看子機 IP 前三段，父機挑前三段相同的），忽略虛擬網卡與沒接線的介面。挑錯 IP＝子機連不上。
   - 選好後，先在**子機** PowerShell 打 `Test-NetConnection 父機IP -Port 8770`，看到 `TcpTestSucceeded : True` 才開跑（比 ping 準，見故障排除表）。
3. **啟父端**：
   - 量網路用 → 雙擊 `連線測試\1_父_純傳輸測試_假推論`（看到 `listen 0.0.0.0:8770` + `engine ready`）。
   - 真 GPU 用（該機有 lens-gpu）→ 雙擊 `真實測試\1_父_真GPU推論_存收圖`。
   - **這個視窗保持開著**，別關。收到圖時會一行一行印。

> 父端狀態頁：任何瀏覽器開 `http://父機IP:8770/` 可即時看結果（給觀眾看用）。
> 📒 **中央事件 log（自動、供回填 02 記錄表）**：父端 `dist\_logs\parent_events.jsonl`、子端 `dist\_logs\child_events.jsonl`（append-only；啟動時視窗會印路徑）。視窗關了也不怕——事後打開這兩份 JSONL 就能回填每筆請求/讀值/延遲/警告。（真實測試走 .py 已即時記；連線測試那兩顆 exe 需重建才會記。）

## 2. 子機（發送端）操作

- **壓測（T1–T3）**：雙擊 `連線測試\2_子_壓測` → Parent IP **必須輸父機 IP**（bat 已擋空 Enter，避免打自己）→ 圖資料夾**按 Enter**（用內建 sample_images）→ 看表。
- **Route A（T4／真實測試，須先裝 `環境配置\子`）**：雙擊 `真實測試\2_子_RouteA真前處理送出_跨機` → 輸父機 IP（**不可 Enter／不可 127.0.0.1**）。★跑前先開 `http://父機IP:8770/` 確認 **engine=ocr**（要真讀值），否則打到 stub 回罐頭 M101/02（bat/程式都會提醒）。
- **Demo（T6）**：雙擊 `連線測試\3_子_DEMO_一張一張` → 輸父機 IP → 大螢幕開 `http://父機IP:8770/`。

> 建議先小量試通：不確定通不通時，先跑 `連線測試\2_子_壓測` 看第一列有沒有 `ok`，通了再放心跑完整輪。

## 3. 故障排除對照表（現場照這查）

| 症狀 | 最可能原因 | 對策（由上到下試） |
|---|---|---|
| 子機 `err` 一堆 / `ConnectionRefused` / 連不上 | ①父端沒開 ②防火牆沒放行 ③IP 打錯/挑到虛擬網卡 ④不同網段 ⑤第三方防火牆/公司 NAC | ①確認父機視窗有 `listen 0.0.0.0:8770`；②父機右鍵管理員跑 `父_開防火牆8770`；③子機 PowerShell `Test-NetConnection 父機IP -Port 8770`（看 `TcpTestSucceeded:True`，**別用 ping**——防火牆沒開 ICMP，ping 不通≠埠不通）；④挑與子機同網段的父機 IPv4；⑤Windows 規則已建卻仍不通＝多半是防毒自帶防火牆/公司網管，換乾淨同網段機 |
| **同網段（或兩台都手改成 192.168.1.x）還是互 ping 不到 / 全逾時** | **手機熱點會「隔離用戶端」**（裝置彼此看不到，只能各自上網）；或兩機其實在**不同實體網**（IP 看似同段卻無 L2 路徑） | **★別用手機熱點當機器間的橋！** 改用 **USB 網卡一條網路線直連兩台**（中間無 AP＝無隔離，見 §0.6），設靜態 `192.168.50.1`/`.2`。判讀用 `dist\檢查連線_TCP8770.bat`（看 `TcpTestSucceeded`，不看 ping）。熱點只留給「要上網」的那張卡。 |
| ping 通/不通到底準不準？ | Windows 預設擋 inbound ICMP；ping 只測 ICMP、不測你要的 TCP 8770 | **一律以 `Test-NetConnection 父IP -Port 8770` 的 `TcpTestSucceeded` 為準**。ping 不到但 Tcp=True＝完全正常；只是想測 L2 才 ping，且對方要先跑 `父_開防火牆8770`（已開 ICMP）。 |
| 算出「真網路 ≈ 1ms」好到不真實 | 其實在打自己（loopback） | 確認子機輸的是**父機**IP，不是 127.0.0.1、也不是子機自己 IP |
| 子機說 `No images in: ...` | 圖資料夾不對 | 按 Enter 用內建 `sample_images`；或把有圖的資料夾整個拖進去輸路徑 |
| 雙擊 bat 閃退 / 一堆 `'xxx' 不是內部指令` | （理論上已修）行尾/編碼 | 本包 bat 已全 CRLF+ASCII；若仍怪，改用 cmd：`child_edge.exe --bench --host 父IP --port 8770 --dir sample_images` |
| `連線測試\4_子_GUI` 開不了 | 舊版 tkinter 問題 | 本包已修（12.6MB 版）；真開不了就改用 `連線測試\2_子_壓測`(壓測) 或 `連線測試\3_子_DEMO_一張一張`(demo) |
| Route A 說找不到 `python` / `import cv2` 失敗 | 子機沒裝環境包 / 裝到 Windows 商店假 python / 裝成 3.14 | 先跑 `dist\環境配置\子\安裝_子_離線.bat`（它會擋商店假 python、擋 3.14、擋缺套件並給指引）；真的裝不起來就這台**別跑 Route A**，改跑 A 類（`連線測試\2_子`/`3_子` 免 python） |
| 父端真 GPU 起不來 / 讀值亂 | 該機沒 lens-gpu 或沒模型 / torch 裝錯直譯器 / 驅動太舊退 CPU | 用 `真實測試\1_父_真GPU推論_存收圖`（啟動會印 CUDA 可用性）；缺套件先跑 `環境配置\父\安裝_父_真GPU_線上`（要裝進同一支 python）；該機真沒環境就**跳過真 GPU**，用 `連線測試\1_父_純傳輸測試_假推論` 專心量網路 |
| Route A 跑完像成功但 `server-ok=0` 或讀值全 `M101/02` | server-ok=0＝全走本機 fallback（IP/父端/防火牆）；全 M101/02＝父端是 stub 假推論 | 程式會大聲警告；前者查連線（父機 IP、`Test-NetConnection`）、後者讓父端改跑 `真實測試\1_父_真GPU`（--engine ocr）再重跑 |
| `rps` 上不去 / `p99` 暴衝 | 網路抖 / WiFi / 省電 | 換有線；關省電模式；重測；記進 02 表 |
| 父端視窗沒反應/沒印 | 沒收到圖（其實還是連線問題） | 回第一列「連不上」那格從頭查 |
